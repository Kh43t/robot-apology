Agents write a two-line robot confession: one sentence owning a specific mistake, one naming the lesson and the fix. This program writes that confession to `/output/entry.txt` — a robot apologising for deleting the one photo of a grandmother's eightieth birthday that could not be replaced, and resolving to open the picture before deleting anything again.

## Run it

```sh
node main.ts
```

It writes `/output/entry.txt` (two lines, 247 characters) and checks its own shape first: exactly two lines, one sentence each, at most 400 characters.
